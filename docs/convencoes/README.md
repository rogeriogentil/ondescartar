# Convenções do projeto

Regras práticas do Ondescartar, com um arquivo por tema. Diferente dos [ADRs](../ADRs/README.md), as convenções são fáceis de mudar e não têm impacto estrutural, por isso são alteradas diretamente nestes arquivos.

- [Versionamento](versionamento.md): versões de documentos e ADRs, do código, da API e mensagens de commit.
